# Corneta • Treinamento

Site estático pronto para GitHub Pages.

## Áudios
Coloque os arquivos MP3 em `assets/audio/` usando exatamente os nomes exibidos no final da página.

## Vídeos
Opcionalmente coloque os vídeos MP4 em `assets/video/` com os mesmos nomes indicados no código.

## GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todo o conteúdo desta pasta.
3. Vá em Settings → Pages.
4. Em Source, escolha Deploy from a branch.
5. Selecione `main` e `/ (root)`.
6. Salve.

O site funciona sem backend e salva as estatísticas de treino no navegador.
